#                                             STATBOT-PRO
#                                     AI-Powered CSV Data Analyst

An end-to-end web application that allows users to upload CSV files, ask questions in natural language, and get instant insights with visualizations.


 # Problem

Analyzing CSV data usually requires:

* Writing Python code
* Understanding Pandas
* Manually creating graphs

This makes data analysis time-consuming and difficult for beginners.


# Solution

This project provides a simple AI-powered interface where users can:

* Upload a dataset
* Ask questions in plain English
* Get instant answers and charts



# Features

* 📂 Upload CSV files
* 💬 Ask questions in natural language
* 📊 Automatic data analysis using Pandas
* 📈 Graph generation (Matplotlib)
* ⚡ FastAPI backend for high performance
* 🎨 React frontend for smooth user experience


# Tech Stack

**Frontend**

* React.js
* Axios

**Backend**

* FastAPI
* Python
* Pandas
* Matplotlib

**AI Integration**

* LLM (via API)


# How It Works

1. User uploads a CSV file
2. File is stored on the backend
3. User asks a question
4. AI agent processes the query
5. Pandas analyzes the data
6. Response (and graph if needed) is returned
